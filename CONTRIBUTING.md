# Contributing

Use Node.js 22 or 24 and npm. Install using `npm ci`. Run `npm run check`, `npm run format:check`, and `npm run test:package` before submitting a change. Add behavior-focused tests for public API changes and regressions. Keep modules independently importable, avoid runtime dependencies, and do not add mandatory Express/Mongoose dependencies. Update README examples and CHANGELOG when behavior changes. Do not commit tokens, .env files, credentials, or user data.

For a security issue, avoid posting sensitive exploit or credential details in public issues. Contact the maintainer privately through their GitHub profile first.
